## 1. Eisenstein Norm

The Eisenstein norm `N(a, b) = a² - ab + b²` measures distance in the Eisenstein integer lattice. Used for tile pattern matching via bitvector fingerprints.

| Language | Function | Location | Key Difference |
|----------|----------|----------|---------------|
| Python | `bitvector.eisenstein_norm(a, b)` | `eisenstein-embed` package | Returns Python `int`, wraps numpy for batch ops |
| Rust | `eisenstein_norm(a: c_int, b: c_int) -> c_int` | `superinstance-ffi/src/lib.rs` | FFI-exported, used from Python via ctypes |
| C | `int eisenstein_norm(int a, int b)` | `superinstance-ffi/superinstance_ffi.h` | Auto-generated by cbindgen, identical to Rust |
| CUDA | Inlined in `eisenstein_embed` kernels | `eisenstein-embed` package | GPU-batched via CuPy kernel |

### Python
```python
# From eisenstein-embed bitvector module
def eisenstein_norm(a: int, b: int) -> int:
    """N(a,b) = a² - a·b + b²"""
    return a * a - a * b + b * b

# Batch version via numpy
import numpy as np
def eisenstein_norm_batch(a: np.ndarray, b: np.ndarray) -> np.ndarray:
    return a * a - a * b + b * b
```

## 2. Constraint Satisfaction (Laman Rigidity)

Laman's theorem characterizes minimally rigid graphs in 2D: a graph with `n` vertices is generically minimally rigid iff it has exactly `2n - 3` edges and every subset of `k` vertices spans at most `2k - 3` edges.

| Language | Function | Location | Key Difference |
|----------|----------|----------|---------------|
| Python | `check_constraint(x, y)` | `constraint_theory` package | High-level satisfiability check |
| Python | `ConstraintCollector` / `ConstraintCompiler` | `superinstance.plugins.constraint` | Fleet-wide constraint aggregation |
| Rust | `laman_is_rigid(n, m)` / `laman_check_subset(n, m)` | `superinstance-ffi/src/lib.rs` | FFI-exported, both subset and full checks |
| C | `int laman_is_rigid(unsigned int, unsigned int)` | `superinstance-ffi/superinstance_ffi.h` | cbindgen-generated header |

### Python
```python
# From constraint_theory package
def check_constraint(x: float, y: float) -> bool:
    """Check if a lattice point satisfies the constraint system."""
    # Eisenstein lattice constraint: N(x, y) must be within bounds
    norm = x * x - x * y + y * y
    return norm <= 1.0

# From superinstance.plugins.constraint — fleet-wide
from superinstance.plugins.constraint import ConstraintCollector, ConstraintCompiler

collector = ConstraintCollector()
collector.add("velocity", lower=-1.0, upper=1.0)
collector.add("acceleration", lower=-0.5, upper=0.5)
compiler = ConstraintCompiler(collector.constraints)
result = compiler.check({"velocity": 0.3, "acceleration": -0.1})
assert result.satisfied
```

### Rust
```rust
// superinstance-ffi/src/lib.rs
use std::ffi::{c_int, c_uint};

/// Verify that a set of edges satisfies Laman's condition for a subset.
/// For k vertices, at most 2k - 3 edges are allowed for minimal rigidity.
#[no_mangle]
pub extern "C" fn laman_check_subset(num_vertices: c_uint, num_edges: c_uint) -> c_int {
    if num_vertices < 2 { return 1; }
    let max_edges = 2 * num_vertices as c_int - 3;
    if num_edges as c_int <= max_edges { 1 } else { 0 }
}

/// Full Laman rigidity test: requires m == 2n - 3.
#[no_mangle]
pub extern "C" fn laman_is_rigid(num_vertices: c_uint, num_edges: c_uint) -> c_int {
    if num_vertices < 2 { return 0; }
    let expected = 2 * num_vertices as c_int - 3;
    if num_edges as c_int == expected { 1 } else { 0 }
}
```

## 3. Fleet Consensus (Holonomy)

Holonomy consensus verifies cycle consistency in fleet graphs. A cycle is consistent if the cumulative state drift around the loop is below a threshold. Uses H¹ cohomology (Betti number β₁ = E − V + C) to detect topological emergence.

| Language | Function | Location | Key Difference |
|----------|----------|----------|---------------|
| Python | `HolonomyConsensus.verify_cycle(cycle)` | `swarm/holonomy_consensus.py` | Full graph + cohomology tracking, emergence detection |
| Python | `HolonomyBridge.check()` | `nexus/holonomy_bridge.py` | Adapter wrapping HolonomyConsensus for fleet agents |
| Rust | `holonomy_check(states, len, threshold)` | `superinstance-ffi/src/lib.rs` | Low-level C FFI, single cycle check only |
| C | `float holonomy_check(const double*, unsigned int, double)` | `superinstance-ffi/superinstance_ffi.h` | Stateless, no graph tracking |

### Python
```python
from nexus.holonomy_bridge import HolonomyBridge

bridge = HolonomyBridge(consistency_threshold=1e-6)
bridge.add_fleet_node("node-a", state=0.0)
bridge.add_fleet_node("node-b", state=0.0)
bridge.add_fleet_node("node-c", state=0.0)
bridge.link("node-a", "node-b")
bridge.link("node-b", "node-c")
bridge.link("node-c", "node-a")

# Verify a specific cycle
report = bridge.verify_cycle(["node-a", "node-b", "node-c"])
assert report.consistent  # All states are 0.0

# Full topology check with cohomology
result = bridge.check()
print(f"β₁ = {result.betti_1}, cycles verified: {result.cycles_verified}")
```

### Rust
```rust
// superinstance-ffi/src/lib.rs
use std::ffi::{c_double, c_float, c_uint};

/// Check holonomic consistency around a cycle of states.
/// Returns 1.0 if consistent (avg drift ≤ threshold), 0.0 if not.
#[no_mangle]
pub extern "C" fn holonomy_check(
    states: *const c_double,
    len: c_uint,
    threshold: c_double,
) -> c_float {
    if len < 2 || states.is_null() { return 1.0; }
    let slice = unsafe { std::slice::from_raw_parts(states, len as usize) };
    let mut total_drift = 0.0;
    for i in 0..slice.len() {
        let a = slice[i];
        let b = slice[(i + 1) % slice.len()];
        total_drift += (a - b).abs();
    }
    let avg_drift = total_drift / slice.len() as f64;
    if avg_drift <= threshold { 1.0 } else { 0.0 }
}
```


## 4. Signal Deadband Filter

Deadband filtering suppresses noise by only propagating signal changes that exceed a minimum threshold. Used for fleet sensor readings and control signals to avoid unnecessary state updates.

| Language | Function | Location | Key Difference |
|----------|----------|----------|---------------|
| Python | Inline in `nerve/fiber.py` | `nerve/fiber.py` signal processing | Python-level, used in fiber routing |
| Rust | `deadband_filter(value, last, deadband)` | `superinstance-ffi/src/lib.rs` | FFI-exported, mutates `last` pointer in-place |
| C | `double deadband_filter(double, double*, double)` | `superinstance-ffi/superinstance_ffi.h` | Direct pointer mutation for state tracking |

### Python
```python
# Pattern used in nerve/fiber.py for signal noise suppression
def deadband_filter(value: float, last: float, deadband: float) -> tuple[float, float]:
    """Apply deadband filter. Returns (output, new_last)."""
    if abs(value - last) < deadband:
        return last, last  # Within deadband — suppress
    return value, value    # Exceeds deadband — propagate

# Usage in fiber routing:
last_reading = 0.0
for reading in sensor_stream:
    filtered, last_reading = deadband_filter(reading, last_reading, deadband=0.1)
```

### Rust
```rust
// superinstance-ffi/src/lib.rs
use std::ffi::c_double;

/// Apply a deadband filter: if |value - last| < deadband, return last.
/// Otherwise return value and update *last via pointer.
#[no_mangle]
pub extern "C" fn deadband_filter(
    value: c_double,
    last: *mut c_double,
    deadband: c_double,
) -> c_double {
    if last.is_null() { return value; }
    let last_val = unsafe { *last };
    if (value - last_val).abs() < deadband {
        last_val
    } else {
        unsafe { *last = value };
        value
    }
}
```

### C

## 5. Spline Interpolation

Hermite cubic spline interpolation for smooth transitions between control points. Used in tensor-spline for adaptive weight parameterization and in signal interpolation.

| Language | Function | Location | Key Difference |
|----------|----------|----------|---------------|
| Python | `SplineLinear` module | `tensor_spline` package | Full PyTorch nn.Module with learnable control points |
| Rust | `spline_interpolate(p0, p1, m0, m1, t)` | `superinstance-ffi/src/lib.rs` | FFI-exported, single-point Hermite interpolation |
| C | `double spline_interpolate(double, double, double, double, double)` | `superinstance-ffi/superinstance_ffi.h` | Stateless, pure function |

### Python
```python
# From tensor_spline package — full PyTorch integration
from tensor_spline import SplineLinear, compression_ratio
import torch

# Learnable spline layer (fewer params than dense linear)
spline = SplineLinear(in_features=64, out_features=64, n_control_points=16)
x = torch.randn(4, 64)
y = spline(x)
assert y.shape == (4, 64)

# Compression ratio
ratio = compression_ratio(spline)
print(f"Compression: {ratio['ratio']:.1f}x fewer parameters")

# Core Hermite interpolation (used internally):
def hermite_interp(p0, p1, m0, m1, t):
    """Cubic Hermite interpolation. t in [0, 1]."""
    t2, t3 = t * t, t * t * t
    h00 = 2*t3 - 3*t2 + 1
    h10 = t3 - 2*t2 + t
    h01 = -2*t3 + 3*t2
    h11 = t3 - t2
    return h00*p0 + h10*m0 + h01*p1 + h11*m1
```

### Rust
```rust
// superinstance-ffi/src/lib.rs
use std::ffi::c_double;

/// Cubic Hermite spline interpolation between two points with tangent control.
/// t in [0,1] blends from p0 to p1 using tangents m0 and m1.
#[no_mangle]
pub extern "C" fn spline_interpolate(
    p0: c_double, p1: c_double,
    m0: c_double, m1: c_double,
    t: c_double,
) -> c_double {
    let t2 = t * t;
    let t3 = t2 * t;
    let h00 = 2.0 * t3 - 3.0 * t2 + 1.0;
    let h10 = t3 - 2.0 * t2 + t;
    let h01 = -2.0 * t3 + 3.0 * t2;
    let h11 = t3 - t2;
    h00 * p0 + h10 * m0 + h01 * p1 + h11 * m1
}
```

### C
```c
// superinstance-ffi/superinstance_ffi.h

```
