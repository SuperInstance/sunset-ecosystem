# sunset-ecosystem

**Sunset ecosystem** — tools and configurations for managing the lifecycle of SuperInstance ecosystem components. Track deprecation, migration, and retirement of services.

## What This Gives You

- **Lifecycle tracking** — monitor which ecosystem components are active, deprecated, or sunset
- **Migration tools** — automate transitions between component versions
- **Configuration management** — centralized config for ecosystem-wide settings

## How It Fits

Infrastructure meta-repo for the SuperInstance ecosystem. Manages the lifecycle of all fleet components.
