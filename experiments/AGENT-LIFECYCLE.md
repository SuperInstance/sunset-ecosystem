# Agent Lifecycle: Read → Build → Write → Read

Every agent cycles through:
1. **READ** — one essay from AI-Writings (5 min)
2. **BUILD** — implement one experiment/test (15 min)  
3. **WRITE** — push results, write findings (5 min)
4. **READ** — next essay (pattern breaks between tasks)

This prevents tunnel vision. The freshest insights come after reading.
